INDUSTRY SOLUTIONS

从一个明确任务开始，再扩成数据闭环

方案不是产品打包，而是先解决需要优先处理的现场问题：改价太慢、清洁人力紧、搬运节拍跟不上、空间说不清效果。跑通之后再按业务需要接入其它产品。

FOUR SCENARIOS

四类场景，四条起步路径

每类场景都标出了起步产品、可扩展产品与需要提前确认的现场条件。

SCENARIO 01 / RETAIL

连锁门店与商超

价格改不动、促销上不齐、纸质标签换不完——先用电子价签把价格链路打通，再用客流数据验证陈列与促销效果。

START 电子价签 + AiESL 数据中台
EXTEND 客流统计、墨水屏标牌、清洁机器人
CHECK 门店数量、货架排布、ERP / POS 接口方式
SCENARIO 02 / PUBLIC SPACE

商业空间与交通枢纽

面积大、人力成本高、空间使用说不清。清洁机器人先承担重复作业，客流与导视数据再支撑排班与运营决策。

START 清洁机器人 + 车队管理后台
EXTEND 客流统计、墨水屏导视标牌
CHECK 地面材质、作业窗口、水电与停放位
SCENARIO 03 / WAREHOUSE

仓储与配送中心

仓储任务需要分别评估搬运与抓取。PanPanTech AMR 用于固定动线上的物料转运；PanPanTech ASR-0012 的抓取与放置任务，需要结合商品、空间与节拍进行开发验证。

START PanPanTech AMR-0300 / AMR-0600 仓储 AMR + 调度系统
EXTEND PanPanTech ASR-0012 抓取验证、货位电子标签
CHECK 通道宽度、载重、对接高度、WMS 接口
SCENARIO 04 / MANUFACTURING

工厂与产线配送

物料配送靠人推车、工位信息靠纸质看板。辊筒型 AMR 与产线自动对接，工位标签随任务同步更新。

START 辊筒型 AMR + 产线对接
EXTEND 工位电子标签、墨水屏看板、清洁机器人
CHECK 节拍要求、MES 接口、人车混行区域
HOW WE ENGAGE

项目怎么推进

先勘测再报价，先试点再复制——这样交付出来的东西才能长期用下去。

01 / SURVEY

现场勘测

平面图、网络条件与作业窗口先确认，再谈产品数量。

02 / PILOT

单点试点

一家门店或一层楼先跑通，把数据口径和运维责任定下来。

03 / INTEGRATE

系统对接

通过 API 与 ERP / POS / WMS / MES 对接，避免两套数据。

04 / ROLL OUT

批量复制

按验证过的配置分批交付，制造与备件由智造中心承接。
