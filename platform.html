AIESL DATA PLATFORM · 平台层

硬件之上，一套统一的任务与审计闭环

AiESL 数据中台承担模板设计、商品与价格数据、批量任务、设备管理、多门店权限与执行审计，并通过 RESTful API 对接 ERP / POS。它属于平台层，支撑六个主营产品，但不是第六个产品。

TASK CHAIN

五段链路，构成可追溯的闭环

从商品中心到现场终端，再把执行结果与设备异常回到平台——每一步都留下可核对的记录。

01 / DATA SOURCE

ERP / POS / 商品中心

承接商品、价格、促销与门店组织等业务数据，字段口径在对接时逐项对齐。

02 / PLATFORM

AiESL 数据中台

把数据变化匹配到货位与模板，生成任务；权限、设备状态与审计都在这一层。

03 / NETWORK

基站 / 网关

以有线或无线网络接入现场，通过私有低功耗协议与终端稳定通信。

04 / TERMINAL

现场终端

价签与墨水屏标牌按任务刷新内容，覆盖常温、冷链与大尺寸场景。

05 / FEEDBACK

执行状态回传

按终端粒度回传结果、电量与异常，形成可派工的失败清单与审计记录。

第 05 段用于回传执行状态，帮助记录任务完成数量、未完成项及异常原因。

CAPABILITIES

平台能力

八项能力覆盖从内容设计到执行留痕的完整运营动作。

可视化模板设计

价格、原价、单位价、会员价与二维码的版式固定下来，避免各门店自行发挥。

商品与价格数据管理

商品编码、规格与货位的对应关系，以及常规价、促销价与生效时间。

批量改价与促销编排

支持按品类或区域分批下发，每批完成即可验收补漏，而不是一次全刷。

终端与基站设备管理

在线状态、电量阈值告警与固件版本，按门店与区域分组查看。

多门店权限与任务分级

总部、区域与门店各自能改哪些范围，让每次操作可以归属到人。

RESTful API 对接

与 ERP / POS / WMS 直连，消除人工导表带来的"两套价格"。

异常告警与执行审计

任务发起人、时间、影响范围与最终结果留痕，可导出用于核查。

SaaS 部署与自动升级

免本地服务器，版本统一，多门店扩容不需要重复部署。

WHICH PRODUCTS

哪些产品接入平台

平台的核心是"把正确的内容送到正确的位置，并把结果收回来"。因此以内容下发为主的产品直接接入，机器人类产品则以任务与状态回传的方式对接。

01 电子价签 ESL模板、价格任务与执行审计的主要使用场景。 05 墨水屏数字标牌商业信息类内容走同一套模板与批量下发逻辑。 02 客流统计以结构化指标接入，用于与价格任务和陈列调整对照。 03 清洁机器人排班任务下发、覆盖率与异常回传，车队记录可回看。 04 拣货机器人搬运任务与执行状态对接，单趟耗时与失败分类可统计。
