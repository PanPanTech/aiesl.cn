AiESL 数据中台

从商品中心到价签执行状态的完整链路

平台不是附加页，而是电子价签解决方案的核心组成部分。

01 / DATA SOURCE

ERP / POS / 商品中心

承接商品、价格、促销与门店组织等业务数据。

02 / PLATFORM

AiESL 数据中台

完成模板、价格任务、权限、设备状态与执行审计。

03 / NETWORK

ESL 基站 / 网关

以有线或无线网络接入门店，通过私有协议稳定通信。

04 / TERMINAL

电子价签终端

按任务刷新价格和促销内容，覆盖常温、冷链与大尺寸场景。

05 / FEEDBACK

执行状态回传

回传任务结果、设备状态与异常信息，形成可追溯闭环。
